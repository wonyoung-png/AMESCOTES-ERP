# 광고 분석 최종 ERP 반영 인계

대표 지시: 2026-10-11 ‘광고까지 넣어라’. 광고 **분석**을 최종 ERP 반영 범위에 포함합니다. 광고 생성·수정·중지·예산 변경은 포함하지 않습니다.

## 책임과 현재 상태

- Codex: 코드 통합·검증. Claude: 운영 적용·DB 적용 및 실환경 검수. 이 문서 자체는 운영 적용 완료 증거가 아닙니다.
- 기능 브랜치 `origin/shop-insight-agents`, 검증된 기능 커밋 `8199c9237aa9f70c55743431e2aa590d4b19bb31`. 기준 통합본 `782ab47`.
- 전체 검증 기록 735건 통과, 최근 기능/격리SQL 재검증 119건 통과. 서로 합산하지 않습니다.
- 실제 Claude 읽기 전용 검토 6회, 합계 USD 4.30. 운영 배포 승인을 의미하지 않습니다.
- 직접 운영 진단 결과: 광고 API/번들 미설치, 광고 테이블 4개 없음, 호스트 Meta 설정이 실행 앱에 전달되지 않음, 맥미니 러너 미설치.

1. 현재 ERP 운영 변경과 충돌·누락을 검수한 뒤 기능 브랜치 통합. 진행 중 체크아웃을 초기화하거나 덮어쓰지 않습니다.
2. 현재 운영 대상 `erp.ameserp.kr`, AWS `ames-new`, `ap-northeast-2`, `i-0cf424d627db8b063`인지 다시 확인. 구 기본 프로필 서버에 적용하지 않습니다.
