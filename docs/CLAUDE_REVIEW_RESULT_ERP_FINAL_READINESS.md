## 이미 알려진 업무 범위 / 검수 인계
- 중국 공장 외부 원가 양식, 공장 월별 취합→지출결의, 작업지시서 불변 버전·외부 전송 확인, 납기 변경 이력은 최종 업무 계약과 대조해야 한다. 기존 문서가 미구현이라고 적은 범위를 완료로 바꾸지 않는다.
- 자재 장바구니는 현재 브라우저 보관이며 기기간 공유를 구현했다고 하지 않는다.
- 불량 책임 확정은 대표, 경비 연결은 대표/경영지원 팀장 승인이다. 「대표 피드백」은 개발 검수 단계 역할을 뜻하며 실제 회사의 금전 승인 권한을 자동 제거하지 않는다.
- 상품 등록은 items를 읽기만 하고 product_listings가 FK로 참조한다. 업무 품목 마스터와 자사몰 공개 등록은 서로 다른 책임이다.
- DB15의 team_agent_runs 실컬럼, 마이그레이션 선행 순서·권한·직원 팀 설정·실제 인증된 업무 종단간과 채널 5개 시나리오 검수는 운영 담당 범위다.
