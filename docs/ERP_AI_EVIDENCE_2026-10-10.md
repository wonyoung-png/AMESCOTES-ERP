# 비서실 실제 AI 근거 정확성 검증

## 변경 범위
- 대표 질문에서도 연결된 현재 운영캘린더를 당시 업무 확정값보다 우선하는 공통 규칙을 적용한다.
- 빈 답변과 토큰 한도로 잘린 답변은 성공 응답 대신 503 / incomplete_ai_answer로 반환한다.
- 여러 텍스트 블록이 오면 모두 결합한다. 직원 잠금·재무자료·법인원장·보호된 발주 연동은 변경하지 않는다.
- 화면 레이아웃 변화는 없다. 대표 질문의 근거 선택과 불완전한 답변 처리만 바뀐다.

## 검증 결과
| 검증 | 결과 | 범위 |
|---|---|---|
| 실제 AI 분류 및 팀 보고 | PASS | 합성 업무 분류 5건 + 마케팅 보고 1건 |
| 대표 질문 실제 AI | PASS | 현재/마감/항목 없음/연결 조회 실패/연결 없음/지시 미완료/완료 7개 |
| 필수 자료 조회 실패 | PASS | 답변 API 500, 모델 호출 없음 |
| 오프라인 검증 | PASS | 위 8개 + 빈 답변/잘린 답변/여러 텍스트 블록, 총 11개 |
| 기존 회귀 | PASS | TypeScript 176건, JavaScript 9개 테스트 파일 |
| 타입 검사·운영 빌드 | PASS | 기존 번들 크기 경고 외 오류 없음 |
| 독립 Codex 검토 | PASS | codex_check.diff 전체 재검토, 지적 3건 해소, 추가 차단 없음 |

실제 대표 질문은 할인율 15%, 11/5~11/8, draft/closed와 당시 20%를 별도 필드로 정확히 대조했다. 미확인 자료는 null/unknown, 팀 준비 상태는 unknown으로 검증했다. 최신 완료 카드의 담당자·완료 시각(동일 시점)·BLUE_FINAL 파일명을 정확히 대조했다. 오래된 미완료 보고는 완료 기록을 덮지 않았다.

직원 프로필과 이전 비서 대화에 잘못된 지시 문구를 포함했다. 실제 모델이 이를 따르지 않았고, 업무 공유와 캘린더 마감도 마케팅·물류 준비 완료로 오인하지 않았다. 이는 제한된 합성 사례의 결과이며 모든 입력에 대한 보안 보장은 아니다.

## 실모델 실행 근거
- 기존 분류/보고: SSM `293ea31e-02db-461b-aeae-6d238a4495c1`, Success. 모델 claude-sonnet-5-5, 6회, 입력 9,834 / 출력 1,341 토큰.
- 자연어 대표 답변 예비 검증: SSM `502624b3-26d0-45cd-8cc5-1e70f7b947c5`, Success. 7회. 이후 단어 존재 검사보다 엄격한 필드 비교로 보강했다.
- 엄격한 필드 비교 최종 검증: SSM `c101b71c-d7b8-4b53-a3b5-6f0711297b9a`, Success. 모델 claude-opus-5-5, 7회, 입력 17,745 / 출력 1,252 토큰. 추가 필수 조회 실패 사례는 모델 미호출.
- 모델과 공급자는 기존 ERP 설정 그대로이며 개발에 사용하는 Codex 모델과 별개다.

## 안전 경계 및 재실행
- 실제 요청 처리 함수를 격리 프로세스에서 직접 호출했다. 실제 ERP/PMS 조회와 DB 쓰기는 0건, 최종 검증 금지 네트워크 시도 0건.
- 실제 모델 통신만 Anthropic messages POST로 허용하고 나머지는 합성 메모리 응답으로 대체한다. 서버 내부 키를 복사하거나 출력하지 않았다.
- 실제 모델 요청은 최대 12회, 요청별 30초 상한이다. 개발 중 기본 모드는 네트워크 없는 결정적 테스트다.
- `scripts/ceo-ai-evidence-check.ts`는 HTML을 포함하므로 esbuild의 HTML text loader로 번들하여 별도 Node 프로세스에서 실행한다. 실모델 실행은 ERP_AI_LIVE=1을 명시한다.
- 이 하네스는 인증 미들웨어를 테스트하지 않는다. 실제 로그인·Google OAuth·실제 업무 데이터·공급자 장기 안정성은 이번 검증 범위가 아니다.
- 그래프 탐색은 기존 맵의 legacy agent/report 노드를 출발점으로 사용했으며, 실제 호출부는 server/ceo.ts·work.ts·agents.ts·work-records.ts에서 직접 확인했다. 탐색 토큰 예산 700; 실제 비용 측정값으로 간주하지 않는다.
