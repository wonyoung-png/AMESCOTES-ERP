# Claude ERP 최종 필수 지적 재검토

2026-10-11 공통 읽기 전용 실행기 실제 성공. 이번 **USD0.65**, 이전 USD7.19 포함 누적 **USD7.84**. 아래는 실제 응답 구조화 요약이며 Claude는 테스트·빌드·DB·서버를 실행하지 않았다.

## 판정
기존 7개 지적(라우트, 명시 수락 담당, 발주 CAS/필드 한정, 원가 자동 청구, 샘플 수금 연결, 불량 미확정, 불완전 보고 제외)은 정적 소스상 모두 해소. 전체 ERP 완료·운영 배포 승인으로 해석하지 않는다.

## 추가 수정 필수 1건
ProductionOrders.tsx의 patchWorkOrder에서 연속 입력이 같은 옛 persistedUpdatedAt을 미리 복사한다. 첫 저장 성공 후 두 번째 요청에 새 원본 버전이 전달되지 않아 충돌하고 화면에만 미저장 내용이 남을 수 있다. 수정 대상: 직전 저장의 확인된 버전 연결과 실패 뒤 후속 저장 보호 및 회귀 테스트.

## 참고 및 운영 보류
- phase1.ts의 과거 미지정 불량을 차감으로 본다는 오래된 주석은 실제 동작과 달라 수정했다.
- 기본 샘플 담당은 기존 대표 인증 계정 `wonyoung@atlm.kr`의 활성·대표 역할이 필요하다. 운영 담당은 실제 팀장 명시 설정과 실제 계정 상태를 확인한다.
- 중국 외부 원가, 작업지시서 불변 버전/외부 전송, 브라우저 자재 장바구니, DB15 실측, 실제 채널 종단간은 여전히 인계 보류사항이다. 완료 오인 위험은 낮다고 판정했다.
- 대표 메모리 결정과 계획 충돌 없음. 운영 DB·실제 채널 검증 미실행 유지.

추가 1건은 초안 predecessor Promise를 따라 성공 버전을 이어받고 실패 후속 저장을 차단하도록 수정했다. 실제 부모 대기열 4건 추가, 전체 564/564 통과, 타입·빌드 재통과. 후속 실제 Claude 검토는 별도 ERP_WORK_ORDER_QUEUE 요청·결과 문서로 기록한다.
