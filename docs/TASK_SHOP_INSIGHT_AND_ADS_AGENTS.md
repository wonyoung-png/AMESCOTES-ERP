## 2. 메타 광고 분석 에이전트 — **분석 전용** (대표 지시 10/11)

> 🔴 **광고·소재 생성/업로드/수정/켜기·끄기 기능을 만들지 않는다.** Meta API 는 읽기(`ads_read`)만. 코드에 쓰기 호출이 있으면 안 된다(테스트로 강제).

### 화면: LUMEN 탭 > "광고 분석"
| 영역 | 내용 |
|---|---|
| 오늘의 분석 | 매일 결과 카드: 합의안 / 이견 / 대표 결정 질문 / 경보, 근거 숫자 펼치기. 국내(lm-kr)·해외(lm-gl) 탭 |
| 질문하기 | 입력창 1개. 예: "지난주 해외 ROAS 왜 떨어졌어?", "LOG MIDDLE 광고 늘려도 돼?" → 진행 상태(Claude 계획 → Codex·Meta 작업 중 → 정리) 표시 → 답변 |
| 기록 | 날짜별 분석·질문 목록, 모델별 원문 보기, 2주 뒤 자동 채점 결과 |
- 비서실(대표 콘솔)에는 오늘의 분석 요약 3줄 + 경보만.

### 데일리 분석 (매일 09:00, 수동 실행 버튼)
1. 수집(규칙, 모델 호출 없음): Marketing API Insights(캠페인·광고세트·광고별 지출·노출·CTR·CPC·CPA·ROAS·빈도) 최근 14일 + 직전 14일, 실제 주문(Shopify·카페24, UTM), 재고. 스냅샷 ID 로 저장 → 세 참가자 모두 같은 스냅샷.
2. 규칙 경보: CPA 급등(7일 평균 대비 +40%), 빈도 3.5↑, CTR 급락, 예산 소진 속도 이상, 품절·재고 부족 상품에 광고비 집행, 계정 결제·정지 상태.
3. 3자 토론(아래 '오케스트레이션' 고정 질문 = "오늘 늘릴/줄일 광고세트, 구조 문제, 근거").
- 단위: 광고세트·캠페인(광고 단위·1주 판단 금지 — 10/11 테스트에서 소표본으로 적중률 낮음).

### 질문하기 = Claude 가 주도, **모델별 결론 → 최종 결론** (대표 지시 10/11)
`server/ads-council.ts` 오케스트레이션 (기존 `server/council.ts` 패턴 재사용):
1. **계획** — Claude Opus 5.5(주도)가 질문을 읽고 계획(JSON): 필요한 데이터(기간·계정·단위·지표), 각 모델에 줄 같은 과제, Meta 에서 가져올 신호(추천·기회 점수·이상 신호·추세). ERP 가 계획대로 스냅샷 생성.
2. **모델별 독립 결론** (서로의 답을 보지 않은 상태, 같은 스냅샷·같은 과제, 같은 JSON 형식: 결론 / 근거 숫자 / 확신도 / 권장 조치):
   - ① Claude Opus 5.5 — 별도 호출(계획 호출과 분리)
   - ② Codex(GPT, 추론 강도 high) — 맥미니 러너
   - ③ Meta — Marketing API 추천/기회 점수/이상 신호 응답을 같은 JSON 형식으로 **변환만** 해서 'Meta 의견'으로 표시(해석·추가 판단 금지, 해당 질문에 Meta 신호가 없으면 '해당 없음')
3. **교차 검토 1회** — Claude·Codex 가 각각 다른 두 의견을 보고 수정/유지 + 이유.
4. **최종 결론** — Claude(주도)가 정리: 합의된 결론 / 모델별 이견(누가 무엇을 왜) / 근거 숫자(스냅샷 출처) / 확신도 / 대표가 정할 것. 스냅샷에 없는 숫자는 제거(council evidence 검증 재사용).
- 화면: 모델별 결론 3칸(Claude·Codex·Meta) + 아래 '최종 결론'. 교차 검토 전후 변경점 표시.
- 데일리 분석도 같은 흐름에 고정 질문("오늘 늘릴/줄일 광고세트, 구조 문제, 근거")을 넣어 돌린다(코드 1벌).
- 질문 원문·외부 텍스트(광고 문구 등)는 데이터로 분리해 인젝션 방지.

### Codex 실행 = 맥미니 러너 (풀 방식)
- ERP 서버(AWS)는 맥미니에 직접 접속할 수 없으므로 **맥미니가 ERP 를 폴링**: `GET /api/ads-council/jobs/next`(러너 토큰) → `codex exec -s read-only -m gpt-6.1-sol -c model_reasoning_effort=high` 로 과제 실행(입력 = 과제 + 스냅샷 파일) → `POST /api/ads-council/jobs/:id/result`.
- 러너: 맥미니 LaunchAgent 1개(`kr.atlm.ads-runner`, 30초 폴링, 스크립트는 레포 `scripts/macmini/ads-runner.sh`). 구독 사용이라 추가 비용 0.
- 맥미니 꺼짐·5분 초과 시 Codex 없이 Claude 단독으로 진행하고 결과에 "Codex 미참여" 표시.
