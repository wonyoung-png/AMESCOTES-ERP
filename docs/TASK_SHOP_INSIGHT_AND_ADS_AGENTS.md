## 2. 메타 광고 — 마케팅 팀 에이전트 확장

### 분석(매일 09:00)
- Meta Marketing API Insights(캠페인·광고세트·광고별 지출·노출·CTR·CPC·CPA·ROAS·빈도) + 실제 주문(Shopify·카페24, UTM) + 재고.
- 규칙 경보: CPA 급등(7일 평균 대비 +40%), 빈도 3.5↑, CTR 급락, 예산 소진 속도 이상, **품절·재고 부족 상품에 광고비 집행**, 계정 결제·정지 상태(이력상 크레딧 한도·compromised 정지 잦음).
- 주 1회 Opus 요약: 잘 되는 소재·안 되는 소재, 다음 주 예산 배분 제안(근거 수치 필수). Meta 보고 전환 / 실제 주문을 따로 표시.

### 3모델 토론으로 결론 (대표 지시 10/11)
10/11 비교 테스트(Documents/meta_ai_truth/RESULT_20261011.md): Claude·Codex·Meta AI 각각 단독으로는 광고 단위 예측 적중률이 낮고 성격이 다름(Claude 적극적 해석, Codex 보수적·수치 정확, Meta AI 계정 구조 권고). → **세 의견을 토론시켜 결론**을 낸다.
- 구조: 기존 `server/council.ts`(2라운드 + 비서실장 정리) 재사용. 참가자를 팀 대신 **모델**로: ① Meta AI = 기회 점수·추천(`ads_get_opportunity_score` 상당 Marketing API) 원문을 근거 자료로 제출(발언은 하지 않음) ② Claude Opus 5.5 ③ Codex(GPT). 라운드1 각자 분석(JSON: 늘릴·줄일 광고세트, 구조 변경, 근거 숫자), 라운드2 상대 의견 반박·수정, 정리는 Opus 비서실장: 합의안 / 이견 / 대표 결정 질문 / 실행안(승인 카드).
- 단위: 광고세트·캠페인, 최근 14일 + 직전 14일 비교(광고 단위·1주는 표본 부족으로 금지). 국내(lm-kr)·해외(lm-gl) 분리.
- Codex 호출: ERP 서버에 OpenAI API 키가 없으면 **맥미니 러너**(codex CLI, 구독 사용, 추론 강도 high 고정)에 SSH/큐로 위임하고 결과 JSON만 ERP로 회신. 실패 시 Codex 없이 2자 토론으로 진행하고 보고에 표시.
- 공정성: 세 참가자에게 같은 데이터 스냅샷 ID, 같은 지시문. 모델별 추론 강도 기록.
- 검증: 매주 결론을 저장해 다음 2주 성과로 자동 채점(적중률·실행안 효과) → 4주 뒤 모델별 기여도 리포트.
- 주기·비용: 주 1회(월 09:00) 기본, 수동 실행 가능. 1회 Claude 3콜(라운드1·2·정리) 약 $0.8 + Codex 구독 0원(API 사용 시 추정 $0.3~0.5) + Meta 0원 → 월 약 5천 원(주 1회).
