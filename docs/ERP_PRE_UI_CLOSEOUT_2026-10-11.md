# UI·UX 전 기능 정비 마감 — 2026-10-11

## 판정 원칙

자동 검증 가능한 구현·연결·회귀를 정비한다. UI·UX 전면 개편, 직원 개방, 재무 실자료 입력·복원, 법인 원장 분리, 은행/외부 회계 연동, AETALOOF 확장은 이번 범위가 아니다. `ERP_PRIVATE_MODE=true`를 유지한다.

ERP 전체의 실제 운영 검증 완료라는 의미는 아니다. 실제 Google OAuth, 외부 재고 의미 대조, 과거 중복 후보의 업무 동일성 판단은 확인 없이 완료로 표시하지 않는다.

## 잔여 항목의 구분

| 구분 | 항목 | 처리 |
|---|---|---|
| 외부 증거 필요 | 실제 Google OAuth 재인증·콜백 | 대표님의 실제 로그인으로 확인 필요; 증명 임의 발급으로 대신하지 않음 |
| 외부 증거 필요 | 이지어드민 I100·실재고 대조 | 동일 시각 SKU/창고/불량/가용 의미 자료 필요; 캐시를 실재고 정본으로 단정하지 않음 |
| 업무 판단 필요 | 과거 중복 일정·추천·BOM | 실제 같은 업무인지 확인 후 정리; 원본 자동 삭제·병합하지 않음 |
