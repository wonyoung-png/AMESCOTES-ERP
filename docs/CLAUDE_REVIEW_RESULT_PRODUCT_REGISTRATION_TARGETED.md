## 낮은 심각도 후속 / 판단
- preorder_gate 차단 이유 표시 누락: 사유 3종을 화면에 표시하고 해당 구역 자동 펼침·회귀 테스트를 추가해 처리했습니다. 이 추가 수정은 Codex 검증이며 Claude가 다시 판정한 내용은 아닙니다.
- previously_public 해제 없음: 현재 의도적 비공개 액션이 없으므로 실제 결함으로 보지 않음. 향후 비공개 기능 추가 시 관측/공개 의도를 별도 모델링해야 함.
- 재반영 도중 종료일 경과: 먼저 queued SYNC 후 다음 1분 tick에서 종료하므로 일시적 문구 지연 가능. 무조건 재고·라벨을 추정 변경하지 않음.
- B 어댑터 회귀는 reapply 전체 통합 테스트가 아님: 서비스 reapply의 보존 테스트와 어댑터 회귀를 각각 검증했으며 실서버 시나리오4에 종단 검수 남김.

## 운영 인계
정확한 판매 한도·권위있는 실입고 자동 종료 미지원, DB15 적용·ERP 전용 앱 토큰·실서버 5개 시나리오는 별도 검수 범위입니다. 이번 한정 검토는 ERP→대표 콘솔 전체를 다시 검토한 결과가 아닙니다(이전 FINAL/POSTFIX 범위와 구분).

### UncertainWrite 수동 확인 절차
1. 상품 등록 쓰기를 OFF하고 해당 상품/채널/단계·events·마지막 확인 근거를 운영 담당이 조회합니다. 원본 사진·의도 키를 임의 삭제하지 않습니다.
2. 실제 관리자 상품의 ERP 소유 표시·SKU·대표/추가 이미지·파일 참조를 대조합니다. 실제 생성 여부가 확정되지 않으면 재시도하지 않습니다.
3. 조회로 이미 성공한 결과를 소유 증거와 함께 재구성할 수 있는 경우에만 검수자가 복구 계획을 제시합니다. 불확실 기록 삭제·무조건 신규 생성으로 우회하지 않습니다.
4. 독립 승인자 재승인 및 테스트 상품으로 복구 시나리오를 확인한 뒤 상품 쓰기 권한을 복원합니다. 자동 해결 기능이라고 주장하지 않습니다.
